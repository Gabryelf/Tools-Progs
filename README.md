## 📖 О проекте

Этот репозиторий содержит набор полезных Python-приложений, созданных для автоматизации повседневных задач. Все программы имеют интуитивно понятный графический интерфейс и работают на Windows 10/11.

### ✨ Особенности

- 🎨 Современный GUI с поддержкой тем и иконок
- 📹 Демонстрации и инструкции по использованию
- 🚀 Оптимизированная производительность
- 📁 Простота использования
- 🔒 Безопасность и конфиденциальность
- 🔧 Гибкая настройка параметров
- 📦 Готовые сборки для Windows (EXE)
- 🎯 Поддержка множества языков программирования

## Использование наработок

### 1. Клонирование репозитория

```bash
git clone https://github.com/Gabryelf/Tools-Progs.git
cd Tools-Progs
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 📦 Сборка EXE

>Исходники exe файлы собранной программы вы можете найти в самих проектах.

К тому же каждое приложение можно собрать в отдельный EXE файл:

### Screen Recorder

```bash
cd src/screen_recorder
pyinstaller --onefile --windowed --name "ScreenRecorder" main.py
```

### Copy Code Pro

```bash
cd src/copy_code_pro
pyinstaller --onefile --windowed --name "CopyCodePro" --icon assets/icons/app.ico src/main.py
```

## 🛠️ Требования

### Системные требования

- **OS**: Windows 10/11, Linux, macOS
- **Python**: 3.8 или выше
- **RAM**: 4 GB (рекомендуется)
- **Диск**: 200 MB свободного места

### Зависимости

Все зависимости описаны в `requirements.txt`:

```txt
пакет (библиотека) = версия
в каждом приложении свой файл!
```
