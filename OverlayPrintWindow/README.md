# ✏️ Overlay Marker

Простое и элегантное приложение для рисования поверх экрана. Идеально подходит для презентаций, демонстраций и быстрых заметок прямо на рабочем столе.

[![Скачать EXE](https://img.shields.io/badge/⬇️_Overlay_Marker_App_v0.0.4-0078D4?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/Gabryelf/Tools-Progs/tree/main/OverlayPrintWindow/dist/OverlayMarker.exe)

> [!NOTE]
> Изначально идея была реализовать данный функционал в приложении ScreenRecorder, но что бы не перегружать логику
> сделал отдельно. Полностью задача будет реализована когда можно будет добавить шаблоны и функции
> для удобного рисования в момент демонстрации, пока нахожусь на стадии поиска данных решений.


#### Возможности
- ✅ Рисование в любом месте экрана
- 🎨 7 цветов для выбора
- 📏 Регулируемая толщина линии (1-20px)
- 🗑️ Очистка всех линий и отмена последнего действия
- 🎯 Полная блокировка мыши в режиме рисования
- 📌 Работает поверх всех окон
- 🔄 Сворачивание в системный трей
- ⚡ Минималистичный интерфейс с иконками
- 🗯️ Рисуем фигурами или линиями
- 📉 Режим постепенного затухания

## 🔧 Использование

### Overlay Marker

1. **Запуск**: `python main.py`
2. **Вход в режим рисования**: Нажмите кнопку ✏️ или клавишу `F2`
3. **Рисование**: Нажмите и удерживайте ЛКМ в любом месте экрана
4. **Выход из режима**: Нажмите `F2` или `ESC`
5. **Очистка**: Кнопка 🗑️
6. **Отмена**: Кнопка ↩️

#### Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `F2` | Вход/выход из режима рисования |
| `ESC` | Выход из режима рисования / Сворачивание панели |
| `ЛКМ` (удержание) | Рисование в режиме рисования |

#### Управление

| Элемент | Действие |
|---------|----------|
| ✏️ | Включить/выключить режим рисования |
| 🗑️ | Очистить все линии |
| ↩️ | Отменить последнюю линию |
| 🎨 Цветные круги | Выбор цвета пера |
| ⚪ Слайдер | Регулировка толщины линии |
| ⚫ Индикатор | Статус режима (обычный/рисование) |
| Трей | Скрыть/показать панель |

## 🔧 Особенности реализации

### Архитектура
- **MVC паттерн**: Разделение логики, представления и управления
- **Dependency Injection**: Слабая связанность компонентов
- **Single Responsibility**: Каждый модуль отвечает за свою задачу

### Ключевые решения
- **Глобальный хук мыши** через `pynput` для рисования в любом месте экрана
- **Прозрачное окно** с `Qt.WA_TranslucentBackground` для оверлея
- **Блокировка ввода** через `WA_TransparentForMouseEvents` для режима рисования
- **Системный трей** для фоновой работы
- **Минималистичный дизайн** с иконками вместо текста
- **Удобные функции** плавное затухание, отмена линий, стереть все
- **Разновидности написания** рисуйте маркером, линией или фигурами
